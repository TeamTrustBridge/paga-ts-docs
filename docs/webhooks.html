    Webhooks

    Paga's callbacks, and how to verify them.

    Always verify the hash first

    Verify the signature before you act on a callback. Then de-duplicate: Paga retries until you answer, so the same callback will arrive more than once.

    Callbacks

    Checkout payment notification

    #
    Checkout - Handle the payment notification

    amount + timeStamp + paymentReference

    Sent to your callback URL when a Checkout payment completes. Check the hash, then fulfil.

    Delivery: Paga sends this to your callback URL.

    • De-duplicate on the payment reference.

    TypeScript

    verifyCheckoutNotification

    const ok = await verifyCheckoutNotification(payload, receivedHash, hashKey);

    Dynamic virtual account callback

    #
    Dynamic virtual account - Handle the callback

    notificationId + statusCode + externalReferenceNumber + state + outstandingBalance

    Sent to your callBackUrl when a payment request is paid, expires or is cancelled.

    Delivery: Paga sends this to your callback URL.

    • outstandingBalance is signed with two decimals.
    • De-duplicate on notificationId.

    TypeScript

    verifyPaymentCallback

    const ok = await verifyPaymentCallback(payload, receivedHash, hashKey);

    Subsidiary account funding notification

    #
    Subsidiary Accounts - Handle a funding notification

    transactionReference + transactionDate + amount + accountNumber + timestamp

    Sent when someone pays into a subsidiary account.

    Delivery: Paga sends this to your callback URL.

    • The hash travels in the x-paga-hash-v3 header, not the body.

    TypeScript

    verifyFundingNotification

    const ok = await verifyFundingNotification(payload, receivedHash, hashKey);

    Subsidiary charge, top-up or transfer callback

    #
    Subsidiary Accounts - Handle a charge, top-up or transfer callback

    externalReferenceNumber + transactionDate + amount + accountNumber

    Sent when a charge, a top-up or a transfer completes.

    Delivery: Paga sends this to your callback URL.

    • The amount is a formatted string with commas, such as "1,000.00".
    • A transfer sends one callback, for the source account only.

    TypeScript

    verifySubsidiaryOperation

    const ok = await verifySubsidiaryOperation(payload, receivedHash, hashKey);

    Money transfer notification

    #
    Money transfer - Handle the notification

    referenceNumber + transactionDate + transactionId + amount + sessionId

    Sent once a money transfer is processed.

    Delivery: Paga sends this to your `statusCallbackUrl`.

    • The digest travels in the x-paga-hash **header**, not the body.
    • Answer HTTP 200 with {"status": "SUCCESS"} once you have accepted it; Paga retries until it gets that.
    • De-duplicate on referenceNumber.

    TypeScript

    verifyMoneyTransferNotification

    const ok = await verifyMoneyTransferNotification(payload, request.headers["x-paga-hash"], hashKey);

    Persistent payment account callback

    #
    Collect API - Persistent Payment Account callback

    statusCode + accountNumber + amount + clearingFeeAmount + transferFeeAmount

    Sent when a persistent payment account is funded.

    Delivery: Paga sends this to your callback URL.

    • The body's hash field signs the five fields above.
    • The x-paga-hash header signs transactionReference + accountNumber + amount instead.

    TypeScript

    verifyPersistentPaymentAccountCallback

    const ok = await verifyPersistentPaymentAccountCallback(payload, receivedHash, hashKey);

    Direct Debit mandate callback

    #
    Direct Debit - Handle the mandate callback

    statusCode + timeStamp + accountNumber + bankName + referenceNumber + mandateStatus

    Sent when the authorisation transfer arrives and when the bank approves the mandate.

    Delivery: Paga sends this to your mandate callback URL.

    • The timeStamp carries nanosecond precision and must be hashed exactly as received.
    • De-duplicate on notificationId.

    TypeScript

    verifyMandateCallback

    const ok = await verifyMandateCallback(payload, payload.hash, hashKey);

    Direct Debit charge callback

    #
    Direct Debit - Handle the charge callback

    statusCode + referenceNumber + accountReference + amount

    Sent when a mandate charge completes.

    Delivery: Paga sends this to your charge callback URL.

    • The amount is a string with two decimals and no commas, such as "600.00".
    • Decide on statusCode, and look up any non-zero code.

    TypeScript

    verifyChargeCallback

    const ok = await verifyChargeCallback(payload, payload.hash, hashKey);

    USD (ACH, Wire and Swift) payment webhook

    #
    Bank transfer (ACH, Wire and Swift) - Handle the webhook

    no signature

    Sent as CAPTURED when a dollar payment clears, or FUNDING_FAILED if Paga could not fund it.

    Delivery: Paga sends this to your USD callback URL.

    • This webhook carries **no signature** — there is no hash to verify.
    • De-duplicate on referenceNumber plus paymentId.

    TypeScript

    parseUsdPaymentWebhook

    const webhook = parseUsdPaymentWebhook(payload);
if (webhook.event === "CAPTURED") { /* fulfil */ }
