    Check the transaction status

    Find out what happened to a money transfer, airtime purchase or bill payment you already sent.

    Some operations have no callback. The transaction status endpoint tells you where a transaction got to, and it is what you use to resolve an unknown outcome.

    Operations

    Check the transaction status

    #
    Business API POST/transactionStatus principal / credentials headers referenceNumber

    Checks what happened to a transaction you already sent. It covers money transfers, airtime purchases and bill payments.

    • Only the last 48 hours are covered.
    • After a timeout or an ambiguous response, wait at least 5 seconds before the first check.
    • The status field is human-readable and may be reworded — branch on responseCode, not on status.

    TypeScript

    getTransactionStatus

    const status = await client.getTransactionStatus({
  referenceNumber: "PAY-2026-0311",
});
if (status.responseCode === 0) {
  console.log("settled");
}
