    Refunds

    Refund a payment in full or in part, or cancel one that was never paid.

    A refund returns money to the customer. Cancelling a payment request that has not been paid uses the same endpoint — Paga decides which it is from the request's state.

    Operations

    Refund or cancel a payment request

    #
    Collect API POST /refund/v2 HTTP Basic referenceNumber + refundAmount

    Refunds a paid payment request in full or in part, or cancels one that has not been paid.

    • Send one request per partial refund, each with its own referenceNumber.
    • Reusing a referenceNumber returns status code 102 and never refunds twice.

    TypeScript

    refundPayment

    const refund = await client.refundPayment({
  referenceNumber: "RFD-2026-0031",
  paymentRequestReference: "ORD-2026-0187",
  refundAmount: 50,
  reason: "Item out of stock",
});

    Check refund status

    #
    Collect API POST /status HTTP Basic referenceNumber

    Checks whether a payment request was refunded. Call it with the **original** payment request's referenceNumber, not the refund's.

    • data.refundStatus becomes "refunded" once the refund is made.

    TypeScript

    getRefundStatus

    const status = await client.getRefundStatus({
  referenceNumber: "ORD-2026-0187",
});
if (status.data?.refundStatus === "refunded") {
  console.log("refunded");
}
