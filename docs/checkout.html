    Checkout

    Take a card or bank payment on a Paga-hosted page. The customer is redirected to Paga, pays, and Paga notifies your server.

    Checkout is the hosted flow: you send the customer to a Paga page and Paga handles the payment instrument. Use it when you want Paga to own the payment UI rather than building your own.

    Operations

    Verify a charge

    #
    Collect API POST/checkout/transaction/verify HTTP Basic

    Confirms a Checkout payment from your server at any time, using its paymentReference. Uses HTTP Basic only — it sends no hash header.

    • status_code 0 means paid, 2 means pending.
    • A pending charge is a legitimate answer, so the response is returned rather than raised.

    TypeScript

    verifyCharge

    const verified = await client.verifyCharge({
  paymentReference: "PAY-2026-0311",
  publicKey: "YOUR_PUBLIC_KEY",
  amount: 50,
});
if (verified.status_code === 0) {
  console.log("paid");
}
